##  Описание проекта
Разработка десктопного приложения на платформе **WPF (C#)** для сервиса доставки еды. Программа позволяет управлять пользователями, категориями блюд и заказами (платежами), а также строить аналитические диаграммы и экспортировать отчеты в Word и Excel.

##  Реализованный функционал 

1. **База данных:**
   * Спроектирована БД `DB_Ibragimov_Delivery`.
   * Созданы таблицы: `User` (пользователи), `Category` (категории), `Payment` (заказы).
   * Настроены связи (внешние ключи) между таблицами.

2. **Интерфейс и навигация:**
   * Создано главное окно с тремя строками (шапка, контент, подвал).
   * Реализован контейнер `Frame` для загрузки страниц.
   * Добавлены часы (таймер в подвале окна) и кнопка «Назад».
   * Реализовано переключение между **Светлой** и **Тёмной** темами с помощью словарей стилей (`Dictionary.xaml` и `DictionaryDark.xaml`).

3. **Безопасность (Авторизация и Регистрация):**
   * Созданы страницы входа и регистрации.
   * Реализовано **хеширование паролей** (SHA1) перед сохранением в БД.
   * Добавлена проверка пароля (длина, наличие цифр, английская раскладка).
   * Реализована **капча** (появляется после 3-х неудачных попыток входа, запрет на копирование/вставку).

4. **Работа с данными :**
   * Созданы страницы для администратора: таблицы пользователей, категорий и платежей.
   * Реализованы функции добавления, редактирования и удаления записей.
   * Добавлена фильтрация и сортировка для списка пользователей.

5. **Аналитика и отчеты :**
   * Реализована страница построения диаграмм (Chart) с выбором пользователя и типа графика.
   * Написан код **экспорта данных в Word (.docx)** без установленного Microsoft Office (через `OpenXml`).
   * Написан код **экспорта данных в Excel (.xlsx)** аналогичным способом.
